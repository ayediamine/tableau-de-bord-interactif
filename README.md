# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

Ce projet est un tableau de bord interactif en Vue.js 3, utilisant Pinia pour la gestion d’état et Three.js pour l’intégration 3D, offrant une interface moderne et responsive pour la visualisation en temps réel 
de capteurs ou dispositifs connectés. Pour le tester en local, il suffit de cloner le dépôt (git clone ...), entrer dans le dossier, installer les dépendances (npm install) puis lancer le serveur (npm run dev)
